# Peastarvutaja — uus versioon

See komplekt sisaldab kolme terviklikku faili: `index.html`, `styles.css` ja `app.js`.

## Kasutusele võtmine

1. Tee oma praegusest projektikaustast varukoopia.
2. Kopeeri need kolm faili oma projekti ühte kausta.
3. Ava sealt `index.html` brauseris.

Failid peavad olema samas kaustas, sest HTML viitab failidele nimega `styles.css` ja `app.js`.

## Kaks mänguviisi

- **Ajavõistlus:** 90 sekundit, 3–2–1 stardiloendus, tasemed avanevad mängu jooksul. Järgmise taseme avamiseks on vaja 10 õiget vastust parajasti harjutatava uue taseme küsimustele. Iga õige vastus annab avatud taseme järgi 1, 2 või 3 punkti. Tulemused salvestuvad selle brauseri edetabelisse.
- **Harjutamine:** mängija valib nelja taseme vahel ja harjutab ilma taimeri, punktisumma või automaatse tasemevahetuseta. Neljas tase kasutab täisarve 0–100 ning hoiab vastused 100 piires.

## Failide rollid

- `index.html` määrab lehe sisu ja mänguvaadete struktuuri.
- `styles.css` määrab välimuse ning kitsama ekraani paigutuse.
- `app.js` juhib mängurežiime, ülesannete loomist, taimerit, vastuseid ja edetabelit.

Ajavõistluse edetabel säilitab kõik tulemused, kuni vajutad **Tühjenda tulemused**. Kustutamine küsib kinnitust. Harjutusrežiimi tulemusi edetabelisse ei lisata.

Edetabel kasutab brauseri kohalikku salvestusruumi; tulemused ei liigu automaatselt teiste seadmete vahel. Tunnis mitme seadme tulemuste koondamiseks oleks vaja jagatud andmebaasi.
